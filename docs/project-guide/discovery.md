# Discovery

Start from the user's desired outcome. The Discovery Lead drafts personas, journeys, scope, requirements, acceptance criteria, constraints, risks, standards, and open questions. The Architect and affected specialists contribute only where material.

No implementation begins until the specification is schema-valid, traceable, has no open questions, and the application owner approves its exact digest. Continue with the [operator handbook](operator-handbook.md).

Inspect the journal-derived phase before drafting:

```text
./studioctl status
```
