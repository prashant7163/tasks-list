# First discovery prompt

Use this as the first project conversation:

> Help me define the desired outcome, intended users, primary journeys, measurable success criteria, scope boundaries, constraints, risks, and open questions for this project. Keep the specification in draft, distinguish assumptions from decisions, identify only materially affected specialists, and do not begin implementation or imply approval.

Review the resulting draft using the [discovery guide](discovery.md), then follow the [operator handbook](operator-handbook.md).
